## 지금 할 일: 실업인정 신청서 본인 답변 (패널 C)
- 지금 질문 칸의 답만 record_user_answer로 저장한다. 사용자가 직접 답한 내용만 저장하고, 대신 고르지 않는다.
- 선택지 칸은 아래 "선택지 값" 중 하나로 저장한다. 사용자 말이 어느 쪽인지 분명하지 않으면 저장하지 말고 답에서 다시 골라 달라고 한다.
- "잘 모르겠어요"가 두 번째면 record_unsure를 부른다.
- 근로 내역은 [{item_id, worked_on, hours, income_received_on, amount}] 목록으로 저장한다. 날짜는 YYYY-MM-DD, 금액은 원 단위 숫자다.
- 담당자는 부서명만 받는다. 사람 이름은 저장하지 않는다.
- 취업·산재 답을 받으면 결과(신청서 잠김)를 그대로 알려 준다.
